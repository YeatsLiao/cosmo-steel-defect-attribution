帮助与说明
一分钟上手
  1. 在检测工作台从样件库点一张图，系统自动识别
  2. 到归因诊断，确认工艺参数后点「开始归因」
  3. 看主因与证据，点「生成整改工单」并填写责任人
  4. 在整改工单页推进状态：开始整改 → 完成整改 → 关闭工单
  5. 到闭环验证，勾选要纳入的整改工单，跑一次复检推演看降幅
术语解释
整改工单
把归因结论固化成可跟踪的整改任务。生成条件：归因给出主因且建议可执行。输入是缺陷类型、主因、整改措施与责任人，输出是工单号与 待处理 → 处理中 → 已完成 → 已关闭 的状态流转。责任人：质量工程师生成与验收，产线或设备责任人执行。
闭环验证
整改完成后按批次重新抽样，用同一套规则推演缺陷率是否下降。触发条件：该缺陷类已有状态为「已完成」或「已关闭」的工单，在闭环验证第 2 步逐张勾选要纳入的工单。输出复检前后缺陷率、降幅与有效性判定。
预期降幅
规则库给出的、该根因整改后该类缺陷可下降的比例。它是规则经验值，不是实测值。
归因正确率
该类根因被判定正确的比例，来自离线评测集。判断错了，整改就落不到点上。
有效降幅
预期降幅 × 归因正确率。这是真正计入复检结果的降幅。
整体降幅
（复检前缺陷率 − 复检后缺陷率）÷ 复检前缺陷率。它是全局口径，单类整改的有效降幅要小得多，因为只影响这一类在总缺陷里的占比。
工单状态
到「已完成」才可纳入闭环验证；「已关闭」表示该整改项已验收归档、状态不再变更，如需复检其效果仍可在闭环验证中勾选。
复检留痕
每次复检推演都会记下当时纳入了哪几张工单、逐类缺陷率怎么变化，在复检历史页点「查看明细」可以看到。
页面在做什么
  • 首页：平台定位、能力展示与入口
  • 检测工作台：载入或上传图片，识别六类缺陷
  • 归因诊断：结合工艺参数定位根因，给四维贡献度与证据
  • 整改工单：归因结论转工单，跟踪到关闭
  • 闭环验证：逐张勾选整改工单，复检推演验证缺陷率是否下降
  • 知识库：30 条冶金规则，可增删改启停
  • 分析看板：全局指标、分布与趋势
  • 复检历史：历次复检推演的留痕，可展开看纳入了哪些工单与逐类明细
  • 报警历史：按天汇总的严重缺陷与聚集告警
数据来源与口径
  • 指标与看板：由平台样例数据离线计算，用于功能演示。
  • 缺陷图片：来自公开 NEU-DET 数据集。
  • 工艺参数与闭环推演：为模拟数据。
  • 知识库：30 条行业冶金规则。
  • Top5 根因：按评测记录的真实根因统计。
  • 告警规则：单次检出「严重」等级立即告警；某缺陷类型 24 小时内出现超过 3 次触发聚集告警。
