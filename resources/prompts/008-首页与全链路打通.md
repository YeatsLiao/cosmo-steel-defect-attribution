# 008 · 首页 + 全链路打通 + 按钮体检

这一批是收口前最后一批大改。目标是让它成为一个**能从头走到尾、每个按钮点下去都有反应**的产品。

## 体检结论（我先替你查过了）

| 问题 | 现状 | 后果 |
|------|------|------|
| **工单链路断裂（最严重）** | 整改工单页没有任何状态流转按钮，全页只有 5 个重复的「去闭环验证 →」 | 工单状态永远推不动 → 闭环页措施永远灰置「工单未完成」 → 闭环走不通 |
| 面包屑不可点 | 「1 检测 › 2 归因 …」是 span，无点击行为 | 装饰性控件，与左侧导航重复，占顶部一行 |
| 重复入口 | 工单页顶部 + 4 张卡片各一个「去闭环验证 →」 | 同一动作五个入口 |
| 演示导览按钮顶栏常驻 | 「▶ 演示 7」 | demo 感 |
| 缺首页 | 进应用直接落在检测工作台 | 没有产品说明，新用户不知道这是什么 |

## 第十二批 · 首页 + 逻辑修复

```text
本轮允许改动业务逻辑与前端交互（此前只改样式的约束取消），但不得修改任何数字、指标口径与后端接口返回值。

1. 新增「首页」，设为默认落地页，放在左侧导航最顶部（图标为房子）：
   页面自上而下五块，每块一张卡片，不要堆小字：
   - 产品卡：标题「钢材表面质量缺陷智能归因与闭环处置平台」，
     一行副标题「上传钢材表面图片，识别六类缺陷，定位根因，生成整改工单并验证闭环效果」。
     右侧放一个主按钮「开始使用 →」，点击跳到检测工作台。
   - 指标卡：四个数字并排（94.44% / 94.68% / 100.00% / 25.64%），
     标签沿用现有一致口径，点击跳转分析看板。
   - 流程卡：五步横排 ① 检测 ② 归因 ③ 工单 ④ 闭环 ⑤ 看板，
     每步一行说明（检测：上传图片识别六类缺陷；归因：结合工艺参数定位根因；
     工单：生成整改工单并推进状态；闭环：复检推演验证降幅；看板：查看全局指标与趋势），
     每步可点击，点击直接跳到对应页面。
   - 动态卡：最近 3 条告警（复用 /api/alerts），每条一行，无数据显示「暂无告警」。
   - 数据卡：一行文字「缺陷图片来自公开 NEU-DET 数据集，工艺与整改数据为模拟推演」，
     右侧链接「数据来源」打开弹层（内容与页脚弹层一致）。
   首页不放任何表单、不放任何需要登录的内容。

2. 修复工单链路断链（本轮最重要）：
   每张工单卡片必须有一个状态流转按钮，按当前状态显示：
   待处理 → 「开始整改」，点击调用 POST /api/work-orders/{id}/rectify
   处理中 → 「完成整改」，点击调用 POST /api/work-orders/{id}/status，body 为 {"status": "已解决"}
   已解决 → 无操作按钮，显示灰色链接「去闭环验证 →」跳转闭环页
   已关闭 → 无按钮
   按钮点击后卡片状态徽标立即更新并 toast 提示，不要等刷新。
   完成后必须实测一遍：把某张工单从待处理推到已解决，
   再打开闭环验证页，确认该缺陷对应的措施项由灰色「工单未完成」变为可勾选。
   如果不变，就是链路没打通，继续修到通为止。

3. 删除重复与无效控件：
   - 删除顶部水平面包屑「1 检测 › 2 归因 …」（仍是 span，不可点击，与左侧导航重复）
   - 工单页顶部的「去闭环验证 →」按钮删除，只保留每张卡片内的那个
   - 顶栏「演示」按钮删除，导览入口保留在帮助抽屉底部文字链接
   - 进度语义合并到左侧导航：每页项右上角 6px 状态点（完成青 / 当前白 / 未开始灰），
     侧栏底部一行小字「进度 N / 5」

4. 按钮体检（逐个点，报告结果）：
   对我给出的这份清单，逐个实际点击验证，并在回复里输出表格：按钮文案 / 点击后发生了什么 / 是否正常。
   清单（来自我这边实测）：
   检测工作台：演示、告警铃铛、帮助、4 个指标胶囊、上传图片、载入样件、6 张样件卡、载入样件（空态）、检测记录展开、数据来源
   归因诊断：去检测工作台、载入（场景）、4 个表单分组标题、开始归因、3 个子标签（主因与证据 / 改进建议 / 智能问答）、显示全部、数据来源
   整改工单：5 个「去闭环验证 →」、数据来源、新增的流转按钮
   闭环验证：复检推演 / 历史 子标签、开始复检推演、数据来源
   知识库：新增规则、编辑、启停开关、删除、筛选、数据来源
   分析看板：推送告警通知、各图表、数据来源
   要求：
   - 任一按钮点击后必须有可见变化（面板更新 / toast / 页面跳转 / 弹层），没有变化的直接修或删
   - 所有按钮具备四态：默认、hover、点击中 loading（≥300ms 的操作）、禁用
   - 危险操作（删除规则）必须二次确认

5. 现代化交互细节：
   - 页面切换写入 history，浏览器前进/后退可用，左侧导航高亮同步
   - 页面标题随页面变化（如「归因诊断 · 钢材表面质量缺陷智能归因与闭环处置平台」）
   - 列表首次加载显示骨架屏（3 个灰色占位块），数据到位后替换
   - 接口失败时卡片内显示错误态与「重试」按钮，不要静默失败
   - 键盘可达：Tab 能遍历所有按钮，Enter / Space 可触发，focus 有青色描边
```

**验收（这一步一步走一遍，必须全过）**：

1. 打开应用第一屏是首页，有产品说明和五步流程
2. 点首页「开始使用 →」到检测工作台
3. 点任意一张样件卡，识别结果出现（实时推理标签）
4. 点「去归因诊断」到归因页，表单已填充，点「开始归因」出结果
5. 点「生成整改工单」，工单页出现新工单
6. 工单卡上点「开始整改」→ 状态变处理中；再点「完成整改」→ 变已解决
7. 到闭环页，该缺陷的措施项已可勾选，点「开始复检推演」→ 结果带四个数字刷新
8. 到看板，闭环相关指标与复检历史已更新

八步全部走通才算合格。走不通的那一步把现象发我，我再给补丁提示词。
