# 014 前端产品化重构实施说明

对应方案 `013-前端产品化重构方案-v4.md`，本轮按当前基线全部重做，未恢复 v3 归档。改动集中在 `steel-defect-attribution/static/`，未改动任何后端接口、指标数字与归因算法。

## 一、六条要求的落实情况

### 2 首页重做

首屏结构（自上而下）：

1. 定位条：一句话定位、三条能力说明、两个入口按钮、四个规模数字（6 类缺陷 / 30 条规则 / 4 个维度 / 5 步流程）
2. 能力三卡：缺陷识别、归因诊断、整改与闭环验证，每张配真实界面截图，整卡可点直达
3. 双栏：典型使用场景（4 个场景说明平台解决什么问题）与最新告警、核心指标
4. 五步流程条：带完成状态，直接反映当前进度
5. 页脚口径说明（纯文本，无按钮）

配图为真实浏览器截图，存放在 `static/img/cap-detect.png`、`cap-attr.png`、`cap-verify.png`，通过 `?boot=detect|attribute|verify` 深链触发真实数据后截取并裁剪，非手绘示意图。

### 3 流程进度显著化与并发互斥

进度指示器改为真实状态机：

- 流程只统计五步（选样件 / 缺陷识别 / 归因诊断 / 生成工单 / 闭环验证），侧栏底部逐条显示 已完成 / 进行中 / 待进行 / 未开始
- 修掉了原先把「访问看板」当作完成一步的问题，`setFlow("dashboard", true)` 已移除，看板访问不再污染进度
- 步骤可点击跳转，首页流程条与侧栏共用同一份状态

并发与重复触发的处理规则（`TASKS` 任务表 + `AbortController`）：

| 场景 | 行为 |
| --- | --- |
| 归因诊断进行中再次点击 | 按钮置为「归因诊断中…」并禁用，重复点击不产生请求 |
| 归因进行中发起复检推演 | 拦下并提示「归因诊断进行中，请等待完成后再复检」 |
| 复检进行中发起归因 | 同上，按占用任务名提示 |
| 检测进行中切换到另一张样件 | 中断在途请求后发起新请求，不排队、不等待 |
| 已有归因结论后修改工艺参数再点归因 | 弹确认框说明将覆盖当前结论，确认后才重跑 |
| 已有归因结论后切换样件 | 自动清空旧结论并提示需要重新归因，避免结论与样件错配 |
| 参数未变重复点击归因 | 直接重跑，不做多余打扰 |

### 4 术语与流程闭环说明

新增两处业务定义卡，直接放在对应页面顶部：

- 整改工单（整改工单页）：业务含义、触发条件、输入、输出、责任角色，并说明工单状态到达「已完成」后该缺陷类才能进入闭环验证
- 闭环验证（闭环验证页）：业务含义、触发条件、输入、输出、责任角色，并标注结果按规则库推演而非现场实测

降幅口径在闭环验证结果区用修复项与指标变化的对应关系讲清：

- 预期降幅：规则库给出的该根因整改后该类缺陷可下降的比例
- 归因正确率：该类根因判定正确的比例，来自离线评测
- 有效降幅 = 预期降幅 × 归因正确率
- 整体降幅 =（复检前缺陷率 − 复检后缺陷率）÷ 复检前缺陷率
- 明确指出 25.64% 是六类全部整改后的整体降幅，单类整改的有效降幅看着小是因为它只占总缺陷的一部分

同一套解释也写进了帮助抽屉的术语解释，首页与看板的指标项带悬浮提示。

### 5 Tab 交互优化

- 归因诊断：取消「主因与证据 / 改进建议 / 智能问答」三个平铺 Tab，改为单列编号分区（主因结论 → 四维贡献度 → 候选根因 → 证据明细 → 数据不足提示 → 改进建议与整改工单 → 建议可执行率 → 智能问答），顶部加常驻吸顶结论条，「生成整改工单」「看证据」两个动作不再藏在 Tab 里
- 闭环验证：取消「复检推演 / 历史」Tab，改为三步纵向流程（选范围 → 认措施 → 看结果）+ 结果分区，历史记录折叠在页面底部
- 知识库：取消 30 条规则平铺分页，改为 缺陷类型 / 根因维度 / 关键词 三个筛选联动，结果按根因维度分组折叠，显示当前命中条数
- 检测记录与复检历史：统一为展开 / 收起折叠

### 6 整体 UI/UX 统一

- 设计令牌集中在 `:root`：间距 4/8/12/16/20/24、圆角 10/8/6、阴影两级、色板保持原有深色底 + 青色主色
- 卡片内边距统一为 16px（原为 12/14/18/20 混用），面板标题层级统一为 14px/500
- 空态统一为 `.empty-state`（标题 + 说明 + 可选动作），加载态统一为 spinner 与骨架屏，错误态统一为文案 + 重试
- 移除渲染代码里的内联 `margin-top:12px`，改用 `.stack-gap` 等类
- 图表轴单位去重（y 轴名称与刻度百分号重复）、折线数据标签上移避免与相邻点重叠、环形图标签只留百分比交给图例
- 百分比格式统一：整数不补小数位（100% 而非 100.00%），其余保留两位

## 二、验证方式与结果

| 断言 | 结果 |

| 帮助类入口数量 | 1 |
| 首页与页脚的数据来源按钮是否移除 | 已移除 |

## 三、边界与遗留

- 未改动后端接口、指标口径、归因与推演算法，页面上的所有数字仍来自原有接口
- 未引入构建工具与前端框架，仍是原生多文件结构，直接由 FastAPI 托管静态资源
- 保持免登录形态
- `?boot=` 深链参数用于演示与截图，可直达已载入样件、已归因、已复检三种状态，日常使用不受影响
