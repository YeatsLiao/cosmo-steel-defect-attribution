# 010 · 本地改造回传步骤

本地已经直接改了代码（不再靠平台对话生成）。改动打包成两个 zip，按阶段传：

- `04-平台素材/ui_upgrade_static.zip`（43KB）—— 第一轮改造：首页重排、指标去重、归因结论条、视觉体系
- `04-平台素材/ui_v3_static.zip`（774KB）—— 第二轮产品化重构：模态弹窗、帮助入口收敛、并发互斥、归因双栏、降幅构成、首页门户（**包含新的 static/img 三张截图**）

两轮改动是叠加关系，**直接传第二个 zip 即可**，它包含全部最新文件。

## 第二轮改了什么

**操作入口收敛**：顶栏的帮助按钮改成下拉菜单（快速上手 / 页面导航 / 新手导览 / 术语与数据口径），首次访问的气泡提示删除，帮助抽屉里补齐了整改工单与闭环验证的业务定义、触发条件、输入输出与责任角色。

**知识库新增/编辑修复**：原来编辑面板渲染在页面最底部（12 张卡片下面），点完看着像没反应。改为居中模态弹窗，带遮罩、ESC 关闭、保存 loading、成功失败 toast。

**并发互斥**：归因与复检推演各自同时只允许一个任务。新请求会先中止旧请求（AbortController），旧回调检测到失效直接丢弃，不会出现后返回的结果覆盖先返回的情况；执行中切换样件或批次会弹确认。

**归因页分区**：改成左参数右结果双栏，取消平铺 Tab，右侧按结论、证据、建议、问答四个分区纵向排列。

**降幅构成**：闭环结果带下方新增降幅构成组件，三条堆叠条加一张明细表，把整改项对应到工单号、状态与本轮计入的百分点，未完成整改的项显示「未计入」。

**首页门户**：定位句 + 三张真实截图能力卡（识别 / 归因 / 闭环，各带一个关键指标）+ 四个典型场景 + 最新告警。

## 第一轮改了什么

**布局与结构**

- 首页重排：hero + 四指标一行 + 「作业流程 / 最新告警」双栏，去掉首页那块占位的数据来源卡（入口收进页脚）
- 每题页顶部重复的四条指标胶囊条撤掉（只在分析看板保留 KPI 卡），每页省出一行高度
- 侧栏导航加图标、当前项青色渐变键条、每项右上角状态点、底部「进度 N / 5」进度卡

**动线修复**

- 归因页新增常驻「结论条」：主因根因 + 置信度 + 预期降幅 + 「生成整改工单 →」按钮。原来这个按钮藏在「改进建议」子标签里，用户在别的标签下根本看不到
- 归因完成后页面自动滚到结论条（原先停在长长的工艺参数表单那里，结果在屏幕外）
- 工艺参数分组默认只展开「设备参数」，页面短一半
- 工单页空态补了说明和「去归因诊断」按钮
- 工作台空态文案改短，按钮换成主按钮

**闭环口径**

- 复检结果带下方新增口径说明：「本次纳入 1 / 6 类整改项，六类全部整改完成的基准降幅为 25.64%」。不这么做，评委只完成一个缺陷整改后看到「降幅 4.81% · 效果不显著」，会和我们宣传的 25.64% 冲突

**视觉**

- 卡片统一 12px 圆角 + 描边 + 阴影；按钮统一三体系（主/次/危险）四态；输入框统一尺寸与 focus 环
- 表格表头吸顶、隔行底色、行 hover
- 环形图标签改为环内显示百分比，修掉两侧标签溢出被裁的问题
- 修掉两处渲染缺陷：闭环措施清单行距被撑到 107px（徽标换行导致）、页脚与首页块高度失衡
- 静态资源加版本号 `?v=2`，解决浏览器缓存旧样式的问题

## 怎么传回去

### 第一步：上传文件

打开平台任务页 → 上方「文件」标签，覆盖这几个文件（zip 已在沙箱解压时按同样目录）：

- `static/index.html`
- `static/css/app.css`
- `static/js/app.js`
- `static/img/cap-detect.png`、`cap-attr.png`、`cap-verify.png`（三个文件必须一起传，否则首页图示会裂图）

如果文件标签支持上传 zip，直接传 `ui_v3_static.zip`，在终端里解包覆盖：

```bash
cd /workspace
unzip -o ~/ui_v3_static.zip -d /workspace
ls -l static/img/ static/css/app.css
```

（zip 传上去放在哪个目录，按平台提示的路径改一下）

### 第二步：重启服务

```bash
cd /workspace
./stop.sh && ./start.sh
curl -s localhost:8000/api/manifest | head -c 80
```

有输出就是起来了。守护进程如果开着，也可以在平台的「守护」标签里点重启。

### 第三步：验证

浏览器打开线上地址，按 Ctrl+Shift+R 硬刷新，然后走一遍：

1. 首页第一屏是产品说明 + 四指标 + 流程
2. 侧栏有图标和进度卡，顶部没有多余胶囊条
3. 载入样件 → 识别结果
4. 归因 → 页面自动滚到结论条，能直接看到「生成整改工单 →」
5. 生成工单 → 工单页点「开始整改」→「完成整改」
6. 闭环页勾选措施 → 开始复检推演 → 结果带出数字，下面有口径说明
7. 浏览器后退能回上一页

### 第四步：重新发布

平台「发布」标签再提一次发布申请，等过审。
