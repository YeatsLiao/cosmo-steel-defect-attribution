## 二、交互状态设计

### 任务状态

| 状态 | 主按钮 | 页面表现 |
|------|--------|---------|
| 空闲 | 可点 | 正常 |
| 执行中 | 转圈 + 禁用 | 结果区显示骨架屏，顶部状态条显示「归因中…」 |
| 完成 | 恢复可点 | 结果回填 + toast |
| 失败 | 变为「重试」 | 结果区显示错误态与重试按钮 |

### 三条并发规则

1. **同类互斥**：归因、推演各自同时只允许一个任务。用模块级 `runToken`，新请求先 `abort()` 掉旧的（`AbortController`），旧请求的回调检测 token 不匹配直接丢弃，绝不覆盖新结果。
2. **可切换**：执行中点其它样件或换批次 → 弹确认「当前任务未完成，切换将取消」，确认才取消并重跑，不静默丢弃。
3. **可恢复**：执行中切页任务不中断（状态存模块级），回到该页自动回填；失败给重试按钮。

### 进度显著化

侧栏底部「进度 N / 5」升级为：五步进度条 + 当前步骤名 + 「下一步做什么」一句话链接（如「下一步：进入归因诊断 →」）。状态由真实数据驱动：已载入样件 / 有检测结果 / 已归因 / 有工单 / 有复检记录。

## 三、术语与流程闭环说明

### 术语定义（页内说明卡 + 帮助中心各一份）

**整改工单**

- 是什么：把一条归因结论转成可派发、可跟踪的整改任务
- 何时产生：在归因诊断页点「生成整改工单」
- 输入：主因根因、缺陷类型、建议措施、责任人、关联检测记录
- 输出：工单号、状态（待处理 → 处理中 → 已解决 → 已关闭）、整改措施
- 谁负责：质量工程师出结论，班组长或工艺员执行整改

**闭环验证**

- 是什么：整改做完后重新抽检一批样件，看缺陷率到底降没降
- 触发条件：至少一个工单进入「已解决」
- 输入：批次、样本量、纳入验证的整改项
- 输出：复检前缺陷率、复检后缺陷率、降幅、判定
- 谁负责：质量主管判定是否放行；未达标退回继续整改

### 缺陷率怎么降下来的（新增降幅构成组件）

闭环结果区新增一块「降幅构成」，把修复项与指标变化对应起来：

```
复检前 39.17%
  −  龟裂 28.55 个百分点   ← 工单 WO20261013 已解决，降低轧制温度
  −  夹杂 22.42 个百分点   ← 工单未完成，未计入
  ─────────────────────────
复检后 37.28%   降幅 4.81%
```

组件构成：一张横向堆叠条 + 一张明细表（整改项 / 关联工单 / 状态 / 预期贡献 / 是否计入）。未完成整改的项显示为灰色并注明「未计入本次降幅」。下方保留一句口径说明：本页为基于规则库预期降幅的工况推演，接入实测复检数据即为真实值。

## 四、UI 规范表

| 项 | 规范 |
|----|------|
| 间距 | 卡片内 20px、卡片间 16px、区块间 24px，全部 4 的倍数 |
| 字号 | 页面标题 15 / 卡片标题 14 / 正文 13 / 辅助 12 / 数字大 28~30（等宽） |
| 色彩 | 主色青 #2FD4C4 仅用于主操作与关键数值；辅助蓝 #378ADD 信息；橙 #EF9F27 警告；红 #E24B4A 仅用于失败与危险；深灰用于未完成态 |
| 状态反馈 | 每个动作四态：默认 / hover / 执行中 / 禁用；执行中一律转圈 + 文案不变 |
| 加载 | 列表与卡片用骨架屏；按钮用局部转圈，不用全屏遮罩 |
| 空态 | 统一三段：结论句 + 一句说明 + 一个可点动作；不出现纯文字空卡片 |
| 文案 | 按钮 ≤6 字，标题 ≤10 字，提示 ≤20 字；不用「模块建设中」「敬请期待」这类占位语 |

## 六、实施计划

| 步骤 | 内容 | 验收 |
|------|------|------|
| P1 | 任务状态机与并发互斥（runToken + AbortController + 确认切换） | 连点两次「开始归因」只出一个结果；执行中点别的样件弹确认 |
| P2 | 帮助入口收敛（四个入口合一） | 顶栏只剩一个帮助入口，四段内容齐全；页脚只留版权 + 数据来源 |
| P3 | 归因页分区化（取消平铺 Tab，左参数右结果，吸顶小结） | 首屏能看到结论与主按钮；四个结果区都能到达 |
| P4 | 术语说明 + 降幅构成组件 | 工单与闭环的业务定义在页内可查；降幅构成表能对应到工单号 |
| P5 | 首页门户化（真实截图三张能力卡 + 典型场景 + 告警按需展开） | 首屏能感知产品做什么；三张卡可点击进入对应页 |
| P6 | 全站规范收口 + 窄屏 + 八步链路回归 | 文案、间距、状态反馈一致；八步链路重跑通过 |

## 七、边界

- 不改后端接口、不改任何指标数字、不改归因算法
- 演示导览功能保留，收进帮助菜单，不删
- 首页图示用真实运行截图（检测结果 / 归因结论 / 闭环降幅），不放示意图
- 保持免登录
