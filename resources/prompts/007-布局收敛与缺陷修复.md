## 第十一批 · 收敛与修缺陷

```text
不改业务逻辑、数据接口和任何数字。本轮做布局收敛和缺陷修复，不新增任何功能。

1. 删除顶栏「演示」按钮和 7 步导览的顶栏入口：
   顶栏的「▶ 演示 7」按钮整体移除；
   导览功能本身保留，入口改到右上角问号帮助抽屉底部，一行灰色文字链接「新手导览」，
   点击后从第 1 步开始。抽屉结构仍保持两段 + 底部一行链接。

2. 删除水平阶段面包屑行：
   「① 检测 › ② 归因 › ③ 工单 › ④ 闭环 › ⑤ 看板」这一行整体删除，与左侧导航重复。
   进度语义合并进左侧导航：
   每个页面项右上角加一个 6px 状态点——已完成青色实心、当前页白色、未开始灰色描边；
   侧栏底部固定一行小字「进度 N / 5」（N = 已完成步骤数，规则不变：样件/结果/归因/工单/复检）。
   收敛后顶部只保留两层：顶栏（logo + 时钟 + 告警 + 帮助）和指标胶囊行。

3. 归因诊断页禁用逻辑（重新执行，上一轮未生效）：
   未选择样件时：工艺上下文整个卡片 opacity 0.5、pointer-events none，
   「开始归因」按钮禁用；提示卡副标题改为「载入样件后自动填充」。
   选择样件载入后解除置灰。请实际点击验证，不要只改样式。

4. 闭环验证页两处显示缺陷：
   - 灰置行文字重叠：未纳入项右侧「预期降幅 22.42%」与「工单未完成」两个元素换行重叠，
     改为同行排布：勾选框 + 措施名 + 工单号 + 状态徽标 + 预期降幅（右对齐），间距 12px，禁止叠字；
     未纳入项整行只显示灰色，徽标统一文案「工单未完成」。
   - 历史 tab 的分页控件若显示「换页」，改为「上一页 / 下一页」，无数据时隐藏。

5. 检测工作台样件卡英文名：
   取消单行截断，卡片底部改两行：第一行中文 13px 白，第二行英文 11px 灰完整显示，
   卡片高度随之加高，六卡仍等高对齐。

6. 分析看板两处口径澄清：
   - 「闭环达标率 83.33%」副文案改为「6 类缺陷中 5 类降幅达标」
   - 「平均处置时长 2.7 h」保留现有口径小字，若无来源则显示「—」
   - 上排四个大卡与「核心指标」四个小卡保留两层结构，不再增减。

7. 全站禁用态统一：禁用按钮 opacity 0.4 + cursor not-allowed；禁用卡片 0.5。
```

**验收**：顶栏没有「演示」按钮；页面顶部只剩顶栏和指标胶囊两层；左侧导航有状态点和「进度 N/5」；归因页不选样件时表单点不动；闭环页无叠字；样件卡英文完整可读。
