# 006 · 工作流重构与交互定界

这份解决的是比样式更深的问题：**每个页面该让用户干什么，只有一件事；页面之间谁负责什么，边界清楚**。

现状诊断（截图实证）：

- 闭环验证页有「开始复检」和「执行推演」两个按钮做同一件事
- 整改动作在两个页面出现：工单卡上「执行整改 / 推进至 已完成」双按钮并列，闭环页又有可勾选的整改措施清单
- 闭环页推演结果压在页面最底部，用户先看到一堆表单最后才看到结果
- 归因诊断页没选样件时，工艺参数表单照样可以填

整改原则一句话：**整改只发生在工单页，复检只发生在闭环页，每页只有一个主按钮**。

## 第九批 · 闭环与工单工作流重构（本轮核心，先发）

```text
不改业务逻辑、数据接口和任何数字。本轮重构两个页面的操作流。

1. 职责定界（只改界面呈现）：
   整改动作只出现在「整改工单」页；「闭环验证」页只做复检推演，不再承担整改执行。

2. 闭环验证页重排为「结果在上、操作在中、历史在下」：
   - 页面顶部固定四张结果小卡（一行四个）：
     复检前缺陷率 39.17% → 复检后 29.12% → 降幅 25.64% → 判定「闭环有效」
     判定卡用状态胶囊色：闭环有效青、闭环无效红。数字为当前最新一次推演结果。
   - 结果带下方是操作区，分两步显示，步骤标题用 12px 灰色小字：
     第 1 步 选择复检范围：批次下拉 + 样本量输入框
     第 2 步 确认纳入验证的整改项：六类措施列表，
       每项一行：勾选框 + 措施名 + 预期降幅（右对齐青色）+ 对应工单号与状态徽标。
       状态为「已完成」的工单默认勾选；
       状态不是已完成的项显示灰色、不可勾选，右侧标注「工单未完成」。
       勾选只决定「是否纳入本次复检验证」，不改变任何工单状态。
   - 操作区底部唯一主按钮「开始复检推演」（通栏实心青）。
     删除「执行推演」和「开始复检」两个旧按钮，全页只保留这一个主按钮。
   - 推演执行后：结果带四个数字更新，按钮进入加载态，完成后 toast 提示。
   - 页面最底部：复检历史（时间、批次、降幅、判定），每页最多显示 10 条。

3. 整改工单页操作收敛：
   每张工单卡只保留一个主按钮，随状态变化：
   待处理 → 按钮显示「开始整改」，点击后状态变处理中
   处理中 → 按钮显示「完成整改」，点击后状态变已完成
   已完成 → 无按钮，位置显示灰色链接「去闭环验证 →」点击跳闭环页
   删除「执行整改」「推进至 已完成」并列按钮。

4. 全站主按钮唯一原则（每页最多一个实心青色按钮）：
   检测工作台 = 载入样件；归因诊断 = 开始归因；知识库 = 新增规则；
   闭环验证 = 开始复检推演；看板无主按钮；工单页主按钮在卡片内。
   同页其余按钮一律次级描边样式。
```

**验收**：闭环页顶部第一眼就是四个结果数字；全页只有一个大按钮；措施清单里未完成工单的项灰掉不可勾；工单卡上找不到两个并排的操作按钮。

## 第十批 · 残留清理与图表修正

```text
不改业务逻辑、数据接口和数字。本轮清理上一轮没覆盖到的残留问题。

1. 检测工作台样件卡：
   六张卡等高，图高统一 150px；
   卡片底部单行显示：中文名 13px 白 + 英文名 11px 灰，超出省略号，禁止换行
   （现在「麻点 pitted_surface」「氧化皮 rolled_oxide压入」换行挤压）。

2. 归因诊断页：
   未选择样件时，工艺上下文整块置灰（opacity 0.5，pointer-events: none），
   「开始归因」按钮禁用；引导卡显示「请选择样件」+ 次级按钮「去检测工作台」。
   选择样件载入后解除置灰。

3. 分析看板：
   - 删除「指标来源：离线评测（platform_data.json）· 非实时计算」一行
   - 三个环形图去掉图内重复渲染的标题文字（图内又画了一遍「缺陷类型分布」等字样）
   - 缺陷类型分布六类改为青色系单色渐变六阶（#2FD4C4 到 #123247 均匀取色），
     不再使用红橙蓝杂色；严重等级与根因维度两图保持现有四色 + 深灰
   - 严重等级分布图例「正常」改为「无缺陷」（只改图例文字，不改数据）
   - 「近 4 个月缺陷率趋势（数据集覆盖 2026-06 ~ 2026-09）」括号部分移入标题右侧 ⓘ 图标

4. 全站搜索删除以下字样的可见文本（若 005 第七批未发，此条等效执行其第 2 条）：
   「指标来源」「非实时计算」「platform_data.json」「基于规则库」「当前样本：未选择样件」。
   相关口径统一收进页脚「数据来源」弹层（若该弹层不存在，按 005 第七批第 1 条补建）。

5. 页脚收敛为一行：「© 2026 · 钢材表面质量缺陷智能归因与闭环处置平台 · 数据来源」，
   「数据来源」四个字可点击，其余文字 11px 灰。
```

**验收**：样件卡无换行溢出；归因页不选样件时表单不可填；看板饼图无图内标题、缺陷类型分布是青色系；全页搜不到「指标来源」「platform_data.json」字样；页脚一行。
