# 视觉规范 v3 · 投屏大屏（唯一有效稿）

> **生效说明**：此前 v1/v2 类描述作废。本文件为视觉与交互的规范来源；实现以 `static/css/app.css` 为准，评审可对照本文与线上界面。

## 1. 使用场景与原则

| 优先级 | 原则 |
| --- | --- |
| P0 | **投屏可读**：1920×1080 距离 2–4 m 可辨认正文与主结论 |
| P0 | **一屏一事**：每步一个主操作；说明最多一句，长文进帮助抽屉 |
| P1 | **数字与结论优先**：KPI、主因、缺陷名、闭环结果用最大字号档 |
| P1 | **工业深色、克制高光**：无渐变营销底、无密排小字说明 |
| P2 | **信息架构可收敛**：改版时**字号与对比度**不得降级 |

**禁止**

- 正文、表头、流程引导使用 **≤12px**（来源角标、徽章数字除外）
- 同一屏两套「四步」导航（侧栏工序 + 顶栏药丸步骤等）
- 主界面堆叠 `panel-hint` / `guide-line` / `cap-text` 级长说明
- 规范写在文档里、`:root` 里没有对应 CSS 变量

## 2. 设计令牌（实现时必须写入 `static/css/app.css` :root）

### 2.1 色彩

与当前产品主色一致，实现时整站只引用变量名：

```css
:root {
  --bg: #0E1B2E;
  --bg-soft: #10203A;
  --card: #142943;
  --card-2: #172E4C;
  --line: #1E3350;
  --line-soft: #1A2C46;
  --primary: #2FD4C4;
  --primary-dim: rgba(47, 212, 196, 0.14);
  --accent: #378ADD;
  --text: #C5D8EF;           /* v3：正文对比度略高于旧 #A8C0DC */
  --text-strong: #FFFFFF;
  --muted: #8AA4C4;
  --dim: #5E7898;
  --danger: #E24B4A;
  --warn: #EF9F27;
  --ok: #6FAF2E;
  --row-stripe: #12253D;
}
```

图表色序：`#2FD4C4` `#378ADD` `#EF9F27` `#E24B4A` `#8AA4C4` `#5E7898`

### 2.2 字号阶梯（核心）

**`body` 基准 = `var(--fs-body)`，禁止另写裸 `15px` 散落。**

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `--fs-display` | **36px** | 主因一句话、闭环结论标题、首页主标题（可 32–40 区间内调） |
| `--fs-kpi` | **32px** | 看板/首页指标数字、贡献度主数字 |
| `--fs-title` | **20px** | 流程页 H1、模块主标题（`.section-title`） |
| `--fs-panel` | **17px** | 卡片标题 `.panel-title` |
| `--fs-body` | **16px** | 正文、表格单元格、默认按钮、表单输入 |
| `--fs-caption` | **14px** | 表头、标签、次要说明、侧栏菜单项 |
| `--fs-micro` | **13px** | 底栏、时间戳、数据来源（全站用量 &lt; 5% 面积） |

字重：正文 **400**；标题、主按钮 **500**。  
数字、工单号、百分比、时钟：**`--font-mono`**。

### 2.3 间距与圆角

| 令牌 | v3 值 | 说明 |
| --- | --- | --- |
| `--topnav-h` | **72px** | 顶栏可承载更大品牌字 |
| `--statusbar-h` | **40px** | 底栏用 `--fs-micro`，但仍需足够点击/扫视高度 |
| `--sidenav-w` | **240px** | 菜单项 `--fs-caption`，不挤字 |
| `--content-pad` | **24px** | 内容区呼吸感 |
| `--pad-card` | **20px** | 卡片内边距 |
| `--gap` | **16px** | 栅格与栈间距（禁止长期用 12px 作全局 gap） |
| `--r-lg` / `--r-md` / `--r-sm` | **12px** / **8px** / **6px** | |

### 2.4 布局骨架（信息架构）

选定 UX 风向后，在实现 PR 里固定一种；规范只约束**区域职责**：

```
顶栏：品牌 · 时钟/告警 · 帮助（无长文案）
├─ 导航区：侧栏 **或** 左时间轴 **或** 仅顶栏步骤（三选一，不可叠加）
├─ 流程条（可选）：仅「样件摘要 + 一句引导 + 主按钮」，**不**重复四步名
├─ 主工作区：识别 / 归因结论 / 工单 / 验证（结论居中放大）
├─ Inspector（可选）：归因工艺参数、验证摘要
└─ 底栏状态条：版权 + 模拟数据一行来源
```

布局以当前 `static/index.html` 四步闭环为准。

## 3. 组件规范

### 3.1 按钮

| 类型 | 高度 | 字号 |
| --- | --- | --- |
| 主按钮 | **44px** | `--fs-body` |
| 默认 | **40px** | `--fs-body` |
| 行内小按钮 | **36px** | `--fs-caption` |

主色实心 `--primary`，字色 `#06231F`；ghost 为 `--line` 边框。

### 3.2 表格

- 表头 / 单元格：**16px**，行高 **≥52px**
- 隔行 `--row-stripe`；悬停略提亮

### 3.3 指标与归因

- 指标卡：标签 `--fs-caption` + 数值 `--fs-kpi`
- 主因：`.attr-cause-name` 使用 **`--fs-display`**（当前实现 24px，不达标）
- 贡献度条：轨道高 **14px**；维度名 `--fs-caption`；数值右对齐主色等宽

### 3.4 流程与导航

- 工序文案：**检测 / 归因 / 工单 / 验证**（四字为主）
- 当前步：主色描边或节点光晕；**不**在步骤下挂 11px 副标题（`frail-desc` 类文案应删除或改为 tooltip）
- 顶栏 `#flow-context`：样件字段用 `--fs-caption`，关键编号用 `--fs-body` + mono

### 3.5 文案

- 流程页：每步 **≤40 字** 引导，加粗步骤编号即可
- 首页能力卡：每卡 **≤24 字** 或改为仅标题 + 进入
- 帮助、术语、规则说明：仅 **帮助抽屉**

### 3.6 空态 / 加载

- 空态标题 ≥ `--fs-panel`，说明 ≥ `--fs-caption`
- 禁止大块留白且无占位

## 4. 页面级最低要求（验收用）

| 页面 | 必须「撑满」的元素 |
| --- | --- |
| 首页 | 主标题 `--fs-display`；能力卡标题 `--fs-title` |
| 检测工作台 | 缺陷名 `--fs-display` 档；置信度 `--fs-kpi` 档 |
| 归因 | 主因 `--fs-display`；贡献度 Top1 视觉权重 ≥ 侧栏参数表 |
| 工单 | 列表主列 `--fs-body`；状态标签 `--fs-caption` |
| 闭环验证 | 前后对比数字 `--fs-kpi` |
| 分析看板 | 卡片数字 `--fs-kpi`；图表轴标签 ≥ `--fs-caption` |
| 检测记录 / 运行记录 / 告警日志 | 表格 `--fs-body`；统计块数字 `--fs-kpi` |
| 知识库 / 问答 | 问题与答案正文 `--fs-body`，副标题 `--fs-caption` |
